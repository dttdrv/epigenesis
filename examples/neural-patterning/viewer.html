What this lets you test

Does a variant act through binding? Does restoring that mediator rescue the phenotype? Does the same DNA change behave differently under another signal history?

The model predicts that reduced affinity lowers occupancy above GliA = 0.1 and raises it below 0.1. The neutral point follows from the equations. It is a candidate mechanism to test experimentally.

Mechanism checks and interventions

Allele rescue restores the reference sequence. Mediator rescue retains variant DNA and restores the reference binding multiplier. Phenocopy retains reference DNA and imposes the variant multiplier. These test the implemented causal chain.

Assumptions and scientific scope

    Each position is an independent regulatory system under a fixed gradient. There is no cell migration, tissue mechanics, neural connectivity or cognition in this experiment. Below each plot, lines span contiguous sampled positions where the same Olig2, Nkx2.2 or Irx3 concentration is largest and above 0.5. Dotted lines mark unresolved positions. These marks do not interpolate domain boundaries between samples.
