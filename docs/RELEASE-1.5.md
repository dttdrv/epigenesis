# Epigenesis 1.5

Version 1.5.0 adds reproducible neural-mechanism experiments around the existing
DNA compiler. The compiler still validates a caller-supplied interpretation;
the example consumers own biological models and execution. This is a software
and research milestone. A biologically faithful brain developed from natural
DNA has not been implemented or validated.

## Added capabilities

- An intervention acceptance harness checks environmental dependence, neutral
  mutations, rescue, phenocopy and misleading interpreters.
- A published neural-fate model executes time-dependent signals and records
  numerical checks, with explicit model and biological limits.
- A measured regulatory-sequence experiment preserves held-out predictions,
  competing models and its failed scientific criterion.
- A shared artificial recipe grows cells, neurites and contacts from one
  founder using pinned CX3D source. It imports no final topology. Physical
  attachment, remeshing and exception-path regressions have preserved failing
  witnesses and repaired tests. Activity follows the constructed graph through
  declared LIF dynamics with transmission and lesion controls.
- A natural-DNA consumer joins annotated genomic exons, reconstructs local
  edits and translates validated nucleotide tensors. Examples retain original
  sequence, annotation, allele and unchanged-flank assumptions.
- A sequence-to-binding consumer implements the published FamilyCode
  single-residue calculation. Its frozen benchmark covers 92 mutants and 316
  experimental matrices, with independent numerical replay and explicit clone
  provenance. The 66 clone-supported primary mutants fail all three predictive
  acceptance criteria. Correct software does not make that model adequate.

Each example has its own inputs, provenance, commands and limitations. The
source archive includes the examples and their tests; the installed wheel
continues to provide the compiler and validators. Construction requires Java
11 or newer and is exercised with Temurin 21; the Python paths require 3.11+.

## Compatibility

The package metadata and `brainc.__version__` become `1.5.0`. Existing producer
identities, wire-format versions, frontend profiles and cited standards retain
their distinct versions. In particular, the final compiler pipeline continues
to emit its existing `1.0.0` producer identities. Unchanged inputs and contracts
retain their compiler artifact identities; a package-version bump does not
rewrite sealed artifacts. External executable ABI version 2 and the version-1
compatibility path remain supported.

Experimental consumers bind their own implementation and input digests.
Changes to their semantics require regeneration of their experimental outputs;
they are not hidden changes to the compiler's biological interpretation.

## Evidence and remaining work

On macOS Python 3.11.15, the 1.5.0 candidate runs 476 tests: 473 pass and three
skip for documented absent-sibling or Linux-only requirements. Compiler,
security, installed-data, wheel and source-distribution gates pass locally.
Remote CI and exact GitHub readback are separate publication evidence; a local
pass does not establish untested platforms or biological acceptance.

The final construction witness has 16 cells, 138 neurite segments, 45 contacts
and zero escaped attachment sites. Uniform passive strain and simplified
activity remain uncalibrated biological assumptions. Upstream Java warnings
remain visible. Viewer rendering and interaction are unverified.

Natural sequence-to-development inference, measured circuit function,
time-resolved biological equivalence and whole-brain coverage remain open.
No package-index publication or release tag is implied by updating the source
repository.
